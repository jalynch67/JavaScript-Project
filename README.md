# Forge Your Hero

Forge Your Hero is a single-page RPG character builder created with HTML, CSS, and JavaScript. The project lets users create a character, preview choices in real time, and save completed characters to a collection.

## Live Website

Add the GitHub Pages link here:

`https://github.com/jalynch67/JavaScript-Project`

## Features

- Preview the four available character classes
- Enter a character name and choose a race, class, weapon, and playstyle
- Select up to three abilities
- Update the character preview as form values change
- Display class statistics and recommended weapons
- Generate a random character idea and send it to the builder
- Create and delete saved character cards
- Display matching character and weapon artwork
- Generate random tavern rumours
- Track the current page section while scrolling
- Adapt the layout for desktop, tablet, and mobile screens

## Running the Project Locally

1. Download or clone the repository.
2. Keep the existing folder structure unchanged.
3. Open `index.html` in a web browser.

No packages or additional setup are required.

## Using the Character Builder

1. Open the Builder section.
2. Enter a character name.
3. Choose a race, class, weapon, and playstyle.
4. Select up to three abilities.
5. Add an optional character background.
6. Select **Create Character** to add the character to the Saved Characters section.

Keyboard users can press **Tab** to move through the form and use the **Arrow keys** to move between Playstyle options.

## JavaScript Features

The project uses JavaScript to:

- Listen for form, button, input, change, scroll, and resize events
- Validate required character details
- Update text, images, statistics, and selected states in the DOM
- Create and remove saved character cards
- Generate random values from arrays
- Read class and weapon information from JavaScript objects
- Prevent the character form from reloading the page

## Accessibility

The project includes semantic page sections, labelled form controls, keyboard focus styles, native radio controls, descriptive image text, live status messages, and responsive navigation.
